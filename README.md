# 박예림 — 소개 페이지

관리시스템 유지보수 · 데이터 분석을 담당하는 박예림의 자기소개 웹페이지입니다.
단일 HTML 파일로, 더블클릭하면 브라우저에서 바로 열립니다.

## 열어보기

`index.html`을 더블클릭하세요. 별도 설치나 서버가 필요 없습니다.

## 담긴 것

- 시간대별 인사와 큰 타이포그래피의 첫 화면
- 자기소개 · 키워드(뒤집히는 카드) · 담당 업무 · 일하는 원칙 · 관심 분야
- 저에 대한 OX 퀴즈
- 밝게/어둡게 전환, 스크롤 진행 막대, 맨 위로 가기
- 계절에 맞는 배경 효과, 화면을 걸어다니는 오리지널 캐릭터
- '동작 줄이기' 설정 존중, 모바일 우선 반응형

## 사진 넣기

폴더에 `photo.jpg`를 두면 첫 화면 원형 프로필에 자동으로 표시됩니다.
